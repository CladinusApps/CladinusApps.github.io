SAFETY

Here is exactly what it does.

Fast file search needs deep access to your drives, so we explain it.

Why it asks for administrator rights (Windows)

Reading the NTFS change journal needs administrator rights. That is what lets it catch every change instantly. If you decline the Windows prompt, the app still runs and follows changes by watching folders, which can miss some on very busy drives. On Linux it never needs root to run: it walks your folders and follows changes with inotify.

Only names, sizes and dates

It builds its index from file names, sizes and dates. It doesn't read the contents of your files.

No network, no telemetry

Nova Files Observer doesn't connect to the internet and collects no data. Its index and settings stay on your PC.

Start at sign-in is optional

On Windows, the installer only sets up start at sign-in if you tick that box. It appears in Task Manager under Startup apps, and uninstalling removes its start-up task.

The Windows installer isn't code-signed yet, so Windows SmartScreen, Smart App Control or your antivirus may warn about it. You can check either download with the checksum below, and the FAQ explains what to do. A Microsoft Store version, which Microsoft signs, is planned.

How to install on Linux

The Linux download is a .tar.gz archive, not an installer program. It holds a self-contained app, so you don't need to install .NET. Open a terminal in the folder you downloaded it to, then:

  1. Unpack it: tar -xzf NovaFilesObserver-*-linux-x64.tar.gz
  2. Go into the new folder: cd NovaFilesObserver-*-linux-x64
  3. Install for your user: ./install.sh

To install for all users instead, run sudo PREFIX=/usr/local ./install.sh. To skip installing, run the NovaFilesObserver file in that folder directly. To remove it later, run ./uninstall.sh from the same folder.

FAQ

Good to know.

Windows says "Windows protected your PC"?

New independent apps haven't built up reputation with Microsoft yet, so SmartScreen shows this warning for the installer. It is expected. To continue:

  1. Compare the SHA-256 above with your download (run the PowerShell command shown above in the folder where you saved it).
  2. On the blue screen, click More info, then Run anyway.

If you don't see "Run anyway", right-click the downloaded file, choose Properties, tick Unblock at the bottom, click OK, and run it again.

Windows says the app is blocked, with no "Run anyway" option?

That is Smart App Control, a Windows 11 feature that blocks apps without a trusted signature, with no way to allow a single app. Nova Files Observer isn't signed yet, so on PCs where Smart App Control is on, Windows blocks it.

Your options are to wait for the Microsoft Store version, or to turn Smart App Control off in Windows Security > App & browser control > Smart App Control. Turning it off lowers your protection against unsigned programs, so only do that if you're comfortable with it. On recent Windows 11 updates you can turn it back on later; on older versions you can't without resetting Windows.

Why does my antivirus warn about it? (Windows)

It asks for administrator rights, reads drives at a low level, and isn't signed, which security software can be cautious about in a new app. Compare the SHA-256 on this page with your download to confirm it's untouched. If your antivirus quarantines it, you can report a false positive to the vendor.

Does it need administrator rights to run?

No. On Windows, with them it reads the NTFS change journal and never misses a change. Without them it scans folders and watches for changes, which is a little less complete. If you decline the Windows prompt at start-up, it runs in that mode. On Linux it runs as a normal user and watches folders with inotify.

How do I remove it completely?

On Windows, uninstall it from Settings > Apps. This also removes its start-up task if you enabled it. On Linux, run ./uninstall.sh from the folder you unpacked.

How do I install it on Linux?

Download the Linux archive, unpack it with tar -xzf, and run ./install.sh inside the folder. The steps are under the download button. If you'd rather not install anything, you can run the NovaFilesObserver file from the unpacked folder directly.

Does it collect any data?

No. It doesn't connect to the internet or send anything anywhere. It indexes file names, sizes and dates on your own PC and doesn't read what's inside your files.

Is it free?

Yes, Nova Files Observer is free to download and use.
